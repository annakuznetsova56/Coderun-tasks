# 17. Яндекс Тележенька на CSS

**Статус:** Решена
**Сложность:** Средняя

## Задача

Необходимо сверстать картинку размером **1000x1000 пикселей**, используя только HTML и CSS.

**Запрещено использовать:**
- SVG
- Встроенные изображения (например, `<img src="...">`, `background: url()`)
- JavaScript

## Формат ввода

Решение должно быть представлено в виде HTML-документа со стилями, вписанными в тег `<style>`.

```html
<style>
    /* стили */
</style>
<body>
    <!-- верстка -->
</body>
```

## Примечание

- Вёрстка должна в точности соответствовать изображению.
- Все числовые значения в оригинальном решении кратны 5.
- Для рисования использовались следующие цвета: `#f45a3b`, `#000000`, `#d8d8d8`, `#ff0000`, `#999999`, `#666666`, `#222222`, `#ffffff`.
